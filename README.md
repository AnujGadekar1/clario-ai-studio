# Clario AI Studio

AI-powered document intelligence platform featuring:

- Hybrid summarization (TF-IDF + BART)
- Emotion detection (RoBERTa)
- Subjectivity & sentiment analysis
- Semantic similarity engine
- RAG-based contextual chat
- AI writing enhancement
- PDF report generation

## Tech Stack

- FastAPI
- Transformers (HuggingFace)
- spaCy
- FAISS
- Gemini API
- Vanilla JS Frontend
